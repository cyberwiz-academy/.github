# CyberWiz Academy

**Learn security by doing it.**

Reading about security only gets you so far. You get good by building a lab, breaking it, and fixing it. CyberWiz Academy shares hands-on labs and guides for students, career changers, and anyone who teaches cybersecurity.

### What's coming

| | |
| --- | --- |
| 🖥️ **Lab builds** | Run a full cybersecurity lab on one or two Proxmox hosts, without a data center budget |
| ☁️ **Cloud and identity labs** | Azure and Entra ID exercises you can run in a free or developer tenant |
| 🛡️ **Blue team practice** | Log analysis, detections, and incident response walkthroughs |

This org is new. Labs land here as they're finished and tested, so watch the org to catch them.

### How the labs work

- **Cheap hardware first.** Labs are built to run on gear you can actually afford.
- **No guesswork.** Each lab says what it teaches, what you need, and how long it takes.
- **Your lab only.** Run these on systems you own or have written permission to test. Never on an employer's, a school's, or anyone else's network.
